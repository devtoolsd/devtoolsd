Kida brings frontend-style component composition to server-rendered Python templates. It supports typed component parameters, named slots, scoped state, error boundaries, block rendering, and compile-time checks for unknown parameters, missing required values, and literal type mismatches. The pure-Python runtime has no dependencies, targets Python 3.14 and free-threaded Python 3.14t, and can render HTML, Markdown, terminal output, and CI reports.
