Rich makes Python terminal output beautiful with zero effort — wrap any `print` call or add `RichHandler` to Python's logging module. Supports syntax-highlighted tracebacks, progress spinners, live tables, Markdown rendering, and side-by-side panels. Powers the Textual TUI framework.
