Mojo is designed to be a superset of Python that can compile to hardware-specific code via MLIR, achieving performance competitive with C++ and CUDA while retaining Python syntax. It targets AI and machine learning engineers who want GPU-level performance without leaving the Python ecosystem. Developed by the team behind LLVM and Swift.
