PRLane gives teams one view of open pull requests from connected GitHub repositories. The merge queue rechecks the approved commit and required checks before merging. CI cost figures are estimates based on runner list rates, not billed charges.

Eligible public GitHub repositories can opt in to free, unlimited PR processing. Private repository plans have a monthly PR allowance and usage-based overages.
