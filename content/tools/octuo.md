# Octuo

Octuo by Tutuo, Inc. is the one place to run the agents you already use. It is the coordinator and unified entry point for heavy agent users who want to string together more agents.

## Overview

You state the goal, and Octuo prepares the work, hands each part to the right agent — Claude Code, Codex, MCP tools, browser and files — and follows up until it is done. Long jobs continue after the chat closes.

## Features

- Canvas views and a visible, editable memory graph
- An encrypted Secrets Vault that the model never sees
- Delegation to the agents you already use, with follow-up until each part is done

## Platforms

The work itself runs on your own Mac (macOS 15+, native, signed and notarized). Tool calls, shell commands and local files stay on the user's machine. The iPhone companion (iOS 18+) shows everything the Mac side sees and lets you answer decisions and tick off checklists on the go, though without a Mac it cannot run tool calls.

## Pricing

Plans from $20/month. 1,000 OC trial credits, no card required.
