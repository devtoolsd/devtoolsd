Cloudbrowser gives developers and AI agents isolated Chrome browsers in the cloud, each with a saved profile. Connect an automation client over authenticated Chrome DevTools Protocol (CDP). Live View shows the Chrome desktop, with read-only and control permissions for authorized users.

Pausing stops compute and keeps the browser profile on disk. Resuming starts Chrome with that profile, which can retain cookies and local storage. Websites may ask users to sign in again. A paused browser can be forked into independent copies for parallel tasks.

Manage browsers and access links in the web console, through the REST API, or with the Go CLI. The CLI has published binaries for macOS, Linux and Windows. Registration is open with email verification. The free plan includes one browser-hour per UTC month and one concurrently running browser.
