easi.run gives each agent an isolated Google Chrome session on your own Linux server. Connect through MCP or REST, watch the session live, take over for a login or approval, then hand control back to the agent. Saved profiles retain browser state between sessions.

Requires a Linux x86-64 server with Docker. The software is open source under AGPL-3.0; server and model costs are separate.
