GTM Tool Finder by OneGTMLab is a free search tool for the API reviews of 66 sales and marketing tools (pricing, rate limits, keys, MCP support), 99 head-to-head comparisons such as Apollo vs Clay, and 110 plain-English definitions of GTM terms. It is available as a web directory, a browser extension and a Python package with a command-line tool. The data ships inside the package and the extension, which send no data anywhere.
