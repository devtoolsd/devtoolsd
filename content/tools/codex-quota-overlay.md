Codex Quota Overlay reads the documented local Codex App Server rate-limits method and renders quota and reset information beside the active Codex conversation. It hides when Codex is not active, never captures screenshots or conversation titles, and keeps quota data in local memory. The project is an independent community project and is not affiliated with OpenAI.
