agent-qa runs natural-language tests against web, Android and iOS apps. Its CLI and local MCP server let coding agents execute tests, inspect screenshots, logs and step evidence, diagnose failures and rerun affected checks.

memidex retains reviewable application facts and reusable procedures. The self-improvement loop keeps lessons supported by validated runs and lets human feedback correct the recorded outcome.

The runtime requires Node.js 24+ and the relevant browser or mobile test environment. Model and external-service costs depend on configuration and usage. Review the [FSL-1.1-ALv2 license](https://github.com/vostride/agent-qa/blob/main/LICENSE.md) for usage terms.
